### Mutation check of the E tests (port temporarily altered, then restored)

Nine single-edit mutations were applied one at a time to a copy of the port
file, `tests/equivalence/test_e_localization.py` was run in strict + research
mode, and the port was restored and byte-compared afterwards. Two kinds of
detection are separated: *source* detection (`test_port_is_verbatim` fails for
every edit by construction) and *numerical/behavioural* detection (any other
test). All nine were detected by at least one numerical/behavioural test.
This is a manual spot check, not a mutation framework.

| Mutation | Numerical/behavioural tests that failed | Why they fail |
|---|---|---|
| start-value clip `1e-9` → `1e-8` | `test_start_values_passed_to_optimizer`, `test_fit_spot_equivalence_and_branch_triggers` | the start vector handed to the optimiser differs from the frozen one by ~9e-9; fitted fields differ |
| `jac_cond < cond_max` → `<=` | `test_cond_max_equality_boundary`, `test_fit_spot_equivalence_and_branch_triggers` | at `cond_max == jac_cond` the port reports SE while the frozen code does not; in the real-fit cases only the `cond_max=None` TypeError text differed (see note) |

### Independent voxel-model check (no `erf`)

Budget fixed before running: `|erf-based − midpoint| ≤ 1e-6 + 1e-6·|midpoint|`;
midpoint sub-samples per voxel are doubled from 64 until two successive results
agree within one tenth of that budget. A fixed `m = 64` does **not** meet the
budget at the smallest baseline sigma (60/65 px; error 1.0e-5), which is why the
density is adaptive. Required `m`: 1024 for σ ≤ 1.4 px, 512 at σ = 3 px, 128 at
σ = 9.2 px; the largest observed |erf − midpoint| over the tested grid was
3.5e-8. A 3D non-cubic example (shape 9×11×13, σz ≠ σy ≠ σx) matches the
product of three independent 1D integrals; an equal-extent y/x variant shows the
check fails when axes are exchanged.

### Limits of this evidence

* The synthetic tests generate data with the model under test; they show
  implementation consistency and parameter recovery on idealised white noise,
  not real-data localization precision.
* Standard errors rely on local linearisation and independent equal-variance
  noise; white-noise success does not validate a real camera noise model.
* Frozen-vs-port equivalence is limited to the inputs listed above, the pinned
  stack, one platform (macOS, Python 3.11) and one process.

### Third audit round (2026-11-10): process umask

`write_outputs` read the process umask with two `os.umask` calls (set, then restore) to set the directory mode. That is a process-wide set-and-restore and races with other
threads (two concurrent writers could leave the umask at 000). The calls and the `chmod` are removed; the published directory keeps `mkdtemp`'s owner-only mode (0700) and the process
umask is never read or changed. Regression test: no `os.umask` call during `write_outputs`, mask unchanged afterwards, directory owner-accessible and never group/world-writable (it failed
before the fix); a 4-thread x 5-write stress run leaves the umask unchanged. strict + research: 385 passed, 3 expected opt-in skips in both environments; main `.venv` without research env
