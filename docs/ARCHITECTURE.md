# CATkit Architecture

Status: **v0.1.0** — M2.0–M2.1 complete; M2.2 A/B/D and M2.3 A/B complete; M2.2-C (automatic threshold) deferred; M3/M4 not started. Implemented modules: `io.py`
(minimal ND2 reader), `segmentation.py`, `detection.py` (fixed_sigma), `localization.py`, `photometry.py`, `cells.py`, `pipeline.py` (single-FOV integration), `qc.py` (overlay),
`provenance.py`, and the CLI (`catkit run`, `catkit env`). The "Current layout" listing below is the M2.0 snapshot; the "Planned modules" table still lists the roadmap
(registration, matching and colocalization are M3, OME-TIFF and Omnipose M4) and is design intent where not listed above.

## Design principles

- One scientific step per module; flat modules, no plugin framework.
- Validated reference algorithms are ported verbatim and checked for numerical
  equivalence against the originals before any refactoring.
- Biological channel identities are never guessed: they come from file metadata
  plus explicit user configuration.
- Every run records its inputs, configuration, calibration, and software versions.
- Optional heavy dependencies (e.g. deep-learning segmentation) stay optional.

## Current layout (Milestone 2.0)

```
pyproject.toml          build system, metadata, dependencies, console script
src/catkit/
    __init__.py         package marker; __version__ (single source of truth)
    __main__.py         enables `python -m catkit`
    cli.py              argparse CLI: `catkit --version`, `catkit env`
    provenance.py       SHA-256, placeholder detection, reference manifest, snapshots
tests/
    test_import.py      import, version consistency, Python version
    test_cli.py         CLI behaviour via both entry points, exit codes
    test_provenance.py  provenance helpers and the manifest tool (fake files)
    equivalence/        isolated access to frozen references (refharness.py),
                        harness self-tests, opt-in reference smoke tests
    deps/               functional checks of the scientific stack (marker `deps`)
tools/
    check_staged.py     pre-commit safety check (file types, size, private deny-list)
    verify_reference_manifest.py   verify all files of the private manifest
    constraints_from_env.py        exact pins of an environment's dependency closure
    reference_fingerprint.py       diagnostic cross-environment numeric fingerprint
constraints/
    py311-research.txt  exact pins used for dependency validation
docs/
    ARCHITECTURE.md     this file
    SCHEMAS.md          data model, coordinates, intensity definitions, outputs (draft v0)
    EQUIVALENCE.md      validation layers, tolerances, isolation rules
    VALIDATION.md       record of executed checks
```

Control flow of a CLI call:

```
catkit env  ──►  .venv/bin/catkit (generated by pip from [project.scripts])
                 └─► catkit.cli:main(argv)
                       ├─ build_parser()      argparse parser + subcommands
                       ├─ parse_args(argv)    --help/--version/invalid args → SystemExit
                       └─ args.func(args)     e.g. cmd_env → returns exit code
python -m catkit env  ──►  catkit/__main__.py  ──►  same main()
```

## Planned modules

| Module | Responsibility | Milestone |
|---|---|---|
| `io.py` | Inspect and load Nikon ND2 and TIFF (explicit axes, channel map and voxel size always required; OME metadata is not interpreted before M4) into a standard `ImageStack` | M2 (minimal explicit-axes TIFF; OME-TIFF parsing M4) |
| `config.py` | Parameters and explicit channel mapping; resolved config saved with each run | M2 |
| `synthetic.py` | Synthetic 3D images with known ground truth | M2 |
| `segmentation.py` | Selectable backends: `otsu` (default, nuclear-stain Otsu), `external` (load a mask), `omnipose` (optional), `both` (run two backends independently and compare; never merged) | M2 (Omnipose M4) |
| `detection.py` | LoG spot detection with noise-normalized thresholds | M2 |
| `localization.py` | Subpixel 3D Gaussian fitting with quality classification | M2 |
| `photometry.py` | Background, aperture intensity, SNR, overlap flags | M2 |
| `cells.py` | Spot-to-cell assignment; per-cell geometry and counts | M2 |
| `pipeline.py` | Single field-of-view orchestration | M2 |
| `qc.py` | QC figures | M2–M3 |
| `registration.py` | Chromatic registration models (`none`, `translation`, `similarity`, `affine`) with held-out validation | M3 |
| `matching.py` | Spot pairing: nearest neighbour, mutual nearest neighbour, Hungarian, radius; unmatched spots retained | M3 |
| `colocalization.py` | Directional colocalization fractions and per-cell summaries | M3 |

Registration (coordinate transform), matching (pairing algorithm), and
colocalization (assessment statistics) are deliberately separate modules.

### Planned outputs

`spots.csv`, `cells.csv`, `pairs.csv`, label masks, QC figures, and
`run_metadata.json`. Exact schemas will be documented in `docs/SCHEMAS.md`
before the pipeline is implemented. Intensity measures (raw peak, Gaussian
amplitude, background, aperture sum, SNR, fit residuals) are stored in
separately named columns and are not interchangeable.
